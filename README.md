## What we build

**Agentic development**
We build with AI agents at every step: specification, implementation, testing and review, with a human approving each change. It applies to ABAP on S/4HANA as much as to TypeScript or Rust, and it is how we keep delivery fast without lowering quality.

**Agentic AI and multi-agent systems**
Orchestrated agent teams with persistent context and human-in-the-loop control. We design agent workflows visually, connect them to tools through MCP, and run them on cloud or self-hosted LLMs.

**SAP, end to end**
- **S/4HANA and ECC**: ABAP backend development
- **SAP BTP**: CAP services, Fiori and SAPUI5 apps, Angular front ends
- **SAP Integration Suite**: integration flows designed, tested and deployed with AI agents
- **SAP SuccessFactors**: side-by-side extensions on BTP, and production support for SuccessFactors Learning
- **Production plumbing**: security, audit logging, central logging and on-premise connectivity

**AI-driven automation**
Work assistants that track cases across ticket systems and prepare answers in advance. Browser automation that agents drive and humans can watch live. Hybrid scraping pipelines that combine selectors and LLM extraction to turn websites into structured data.

**Custom software**
Web platforms, SaaS products, cross-platform desktop apps and developer tooling.
